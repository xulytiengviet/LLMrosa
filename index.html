    04 / Hướng dẫn chạy ROS 2 thật

    Từ website đến Gazebo, Nav2 và ROSA

    Trang này là phần Việt hóa và mô phỏng trên web. Để chạy robot Summit XL thực tế trong Gazebo, dùng mã nguồn bài thực hành ZHAW ở repository riêng.

    1Chuẩn bị môi trường tương thích

    Hướng dẫn Summit dùng ROS 2 Jazzy trong môi trường container chuyên dụng (ví dụ robopaas/rap-jazzy:cuda12.5.0), Gazebo, Nav2 và bản đồ nhà. Ubuntu 24.04 + ROS 2 Jazzy là hướng triển khai phù hợp; cần kiểm tra tương thích GPU và image.

    2Lấy mã nguồn mô phỏng Summit

    Clone ví dụ ZHAW vào workspace trong container đã chuẩn bị. Script init.sh của họ có thao tác cài phụ thuộc và build workspace; nên đọc script trước khi chạy.

    Terminal
    git clone https://github.com/RAP-2025-Project-Group-2/RAP-2025-Project-Group-2.git ~/rap/Gruppe2
    Trong container đã chuẩn bị
    source ~/rap/Gruppe2/init.sh
    3Khởi chạy Gazebo + Nav2

    Chọn bản đồ có sẵn để điều hướng hoặc bật chế độ SLAM khi cần khám phá.

    Điều hướng bằng bản đồ sẵn có
    ros2 launch rosa_summit summit.launch.py
    Chế độ SLAM
    ros2 launch rosa_summit summit.launch.py slam:=True
    4Khởi chạy ROSA và gửi lệnh

    Trong terminal mới cùng workspace, thiết lập thông tin LLM bằng biến môi trường phía máy chủ (không đưa key vào website, ảnh Docker công khai hay Git).

    Chạy agent
    ros2 run rosa_summit rosa_summit

    Ví dụ tương tác: “take me to the kitchen”. Lệnh tiếng Việt cần được kiểm thử với LLM và phần chuẩn hóa tên phòng; không bảo đảm mọi cấu hình agent hiểu tiếng Việt nguyên bản.

    🛡 Nguyên tắc an toàn

    LLM không nên được quyền xuất lệnh trực tiếp đến động cơ. Chỉ công bố các công cụ đã kiểm tra, giới hạn tốc độ và khoảng cách, ràng buộc vùng hoạt động, theo dõi timeout và có dừng khẩn cấp độc lập.

    Đối với robot vật lý, cần kiểm tra cảm biến, tình trạng định vị, mục tiêu có hợp lệ, con người trong vùng nguy hiểm và cơ chế phục hồi lỗi. Mô phỏng tốt không đồng nghĩa đủ an toàn để triển khai.

    🇻🇳 Hướng Việt hóa mở rộng

    Chuẩn hóa câu tiếng Việt → ý định có kiểu → đối chiếu danh sách công cụ → kiểm tra điều kiện → gọi ROS 2 Action. Có thể thêm CVNSS4.0 như lớp biểu diễn/hậu kiểm tiếng Việt, nhưng đây là hướng phát triển tương lai, không phải thành phần vốn có của NASA ROSA.

    Ví dụ Task IR có kiểu (minh họa)
    {
  "intent": "navigate_to_location",
  "location": "kitchen",
  "confirmed": true,
  "mode": "simulation"
}

    🔐 Không đưa API key lên GitHub

    GitHub Pages chỉ phục vụ giao diện tĩnh. Không nhúng khóa Anthropic/OpenAI vào HTML, JavaScript hoặc .env được commit. Muốn kết nối ROS thật phải xây backend có xác thực, kiểm soát quyền, log và lớp an toàn riêng.
